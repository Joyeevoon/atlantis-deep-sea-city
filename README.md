# 亚特兰蒂斯 · 深海圣城

一个用 three.js 做的可交互海底圣城：你可以浏览或第一人称漫游，荡秋千、听人鱼唱歌、
翻开《潮汐之书》、点开藏在贝壳里的记忆、给河水换成落霞粉或极光色，还能和船上三只猫糕打招呼。



## 操作

| 动作 | 说明 |
| --- | --- |
| 右上「浏览 / 漫游」 | 切换环绕浏览与第一人称漫游（漫游：点击画面锁定鼠标，WASD 移动，Shift 奔跑）|
| 底部「清晨 / 黄昏 / 夜晚 / 暴风雷雨」 | 切换光照与天气；黄昏时河水默认是粉色 |
| 左侧「探索指引」 | 一键前往各个地点；新地点旁有快捷按钮 |
| 点击场景 | 电话亭、秋千、图书馆、潮汐之书、人鱼虚影、五只随宠、海神雕像、三枚贝壳、河面、猫糕船 |

### 触屏 / 手机

- 单指拖动旋转视角，双指缩放平移。
- 漫游模式下左下角有摇杆。
- 点开贝壳后，卡片会随手机陀螺仪倾斜（iOS 需要点一下允许），点击图片可保存到相册。
- `?low` 参数或低配设备会自动使用轻量模型。

## 第三方

- three.js r160 及其 addons（`vendor/three-kit.js`，本地打包，不依赖 CDN）。
- 场景中的角色与器物 3D 模型由 Tripo 生成。
